# VIT Student Hub 🎓

A student-focused web application designed for VIT students to access useful campus information and resources through a simple, responsive interface.

## 🌐 Project Overview

**VIT Student Hub** is a React-based student utility website created as part of the **VIT Android Club project/task**.

The goal of the project is to provide students with a convenient and user-friendly hub for accessing important student resources in one place.

The website is designed to work across both **desktop and mobile screens**, with a responsive and clean user interface.

## ✨ Features

* 🎓 Student-focused dashboard
* 📚 Quick access to useful student resources
* 🏫 VIT-focused information and utilities
* 📱 Responsive mobile-friendly design
* 💻 Desktop-friendly layout
* 🎨 Clean and simple user interface
* ⚡ Fast development and build setup using Vite

## 🛠️ Technologies Used

* **React.js**
* **Vite**
* **JavaScript**
* **HTML5**
* **CSS3**
* **ESLint**

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/nandhika19022008-sudo/vit-student-hub.git
```

### 2. Navigate to the project directory

```bash
cd vit-student-hub
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will then be available through the local development URL shown in your terminal.

## 📦 Available Scripts

| Command           | Description                   |
| ----------------- | ----------------------------- |
| `npm run dev`     | Starts the development server |
| `npm run build`   | Creates a production build    |
| `npm run preview` | Previews the production build |
